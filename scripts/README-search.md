# 本地搜索

Hugo 只生成页面, 不会自动生成 Pagefind 索引. 首次本地预览或更新文章后运行:

```sh
python scripts/build_search_index.py
hugo server
```

脚本先构建临时站点, 再把索引写入 Git 忽略的 `static/pagefind/`.
已经启动的 Hugo server 会检测到静态文件变化; 如浏览器曾遇到索引 404, 刷新页面再搜索.
索引覆盖当前正常发布的文章与 Slides, 不包含草稿.
文章修改后需要重新运行脚本更新索引. 线上索引由 GitHub Actions 自动生成.

本地和 CI 固定使用 Pagefind 1.5.2. 升级时需要同时调整构建脚本与工作流.

搜索在页面空闲时预热引擎与元数据, 输入查询后再下载所需索引片段.
标签列表仅进入标签模式时加载. 加载期间的输入会保留, 准备完成后自动搜索最新查询.
结果按下载完成情况逐步显示, 保持搜索排名, 不等待最慢的一条结果才显示整组.
网络错误或超过 15 秒的等待会显示重试入口.
